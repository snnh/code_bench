## 说明

* 满分 30；`积分` 为该子项一次完整复刻的得分
* `成本(折算API价格)`：按模型官方/中转 API 价格折算的一次评测费用，区间表示按档位估算，`-` 为未统计

* `缓存`：prompt cache 命中率与命中 token 量
* 缺测显示 `-` 或 `未测试`；表格默认按积分降序，点表头可切换升降序，缺测始终排在最后
